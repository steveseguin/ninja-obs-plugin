Native receiver · Six-channel audio

Keep all six channels.

Bring a compatible six-channel stream into OBS as one 5.1 audio source.

Requires the plugin release containing six-channel reception and a sender that actually publishes six-channel multiopus. A stereo source remains stereo.

1Choose the OBS audio layout

In Settings → Audio → Channels, choose 5.1 and use 48 kHz. Restart OBS if prompted. This changes the audio layout for the whole OBS profile; use a separate profile if your normal show is stereo.

2Add the native receiver

Add a VDO.Ninja Source, enter the sender's stream ID and matching password, and enable Use Native Receiver (Experimental). The plugin negotiates six channels automatically when the sender offers a supported format.

The browser-backed source is a different playback path. This guide covers the native receiver.

3Record and check each channel

Route the source to your recording track in Advanced Audio Properties. Record an MKV with an audio encoder supporting 5.1, such as AAC. Have the sender play a sound on each channel separately, then inspect the recording in a player or editor that exposes all six channels.

This preserves six channels within one audio stream. It does not create six independently controlled OBS sources or six recording tracks.

If your show is stereo

Keep OBS set to Stereo. OBS downmixes the received 5.1 source: front, center and rear channels contribute to left/right; the LFE channel is omitted. Do not put an essential isolated voice only on channel 4 if you need stereo playback.

Ordinary mono/stereo Opus senders continue to work normally. This feature does not change the plugin's publishing audio or Guest Return.

Compatibility and validation

Supported input is multiopus/48000/6 with valid stream counts and channel mapping. The tested Game Capture candidate uses four streams, two coupled streams, and mapping 0,4,1,2,3,5.

Portable Windows OBS checks use distinct synthetic capture tones, real encoding/WebRTC/native decoding, and actual AAC recordings. They check channel order, stereo downmix and reconnection. They do not qualify physical six-input hardware or a sender's release readiness. The Game Capture six-channel sender remains a separate experimental feature.

Six-channel reception is part of the experimental native receiver. Keep the sender and recording destination compatible with the selected audio layout.
