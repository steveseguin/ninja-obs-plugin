Host checklist · Before the show

Check the whole room.

Rehearse with the actual guest count, devices and connections you will use live.

Use plugin v1.1.79. For 20 guests, allow 22 viewer slots and choose a tested return preset. Allow about 26 or 47 Mbps upload for the return, plus your public stream and other uploads. Your public audience does not consume return viewer slots.

Checks apply to this rehearsal only. This page does not save or transmit your answers.

Custom networks and TURN

Open Advanced connection settings only when needed. Custom signaling and salt must match the room. Force TURN requires a working UDP TURN server entry. The bundled backend does not support TCP/TLS-only TURN networks.

Copied invites omit TURN credentials. A forced relay setting is not proof of a relay connection; verify the selected ICE candidate pair when diagnosing a restricted network.
